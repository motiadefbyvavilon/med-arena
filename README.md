# МедАрена — спортивное врачевание

Фронтенд-приложение на **Vue 3 + Vite**: платформа, где молодые врачи прокачивают
клиническое мышление, решая интерактивные кейсы — по аналогии со спортивным
программированием.

## Возможности

1. **Банк кейсов**
   - 8 клинических кейсов по 7 специальностям (кардиология, неотложная помощь,
     эндокринология, неврология, пульмонология, хирургия, педиатрия).
   - Сложность по уровням: Интерн / Ординатор / Врач (100 / 200 / 300 баллов).
   - Фильтры по специальности, сложности и статусу (решённые / нерешённые).

2. **Решение кейса**
   - Полная клиническая картина: жалобы, анамнез, витальные показатели, данные обследований.
   - Вопросы с вариантами ответа, мгновенная проверка и подробный разбор после каждого ответа.
   - Баллы начисляются только за верный ответ с первой попытки.

3. **Прогресс и уровни**
   - Счёт баллов, точность ответов, прогресс по специальностям, история решённых кейсов.
   - Уровни: Студент → Интерн (300) → Ординатор (800) → Врач (1500).

4. **Таблица лидеров**
   - Рейтинг участников сезона; строка пользователя рассчитывается из реальных баллов.

Прогресс хранится в `localStorage` браузера (демо-режим без бэкенда).

## Стек

- Vue 3 (Composition API, `<script setup>`)
- Vite
- Vue Router 4
- Pinia
- Без UI-библиотек: собственные компоненты и дизайн-токены (OKLCH)

## Запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # продакшн-сборка в dist/
npm run preview  # просмотр продакшн-сборки
```

## Структура

```
src/
├── main.js
├── App.vue                # каркас: шапка, навигация, счёт игрока
├── router/                # Прогресс / Кейсы / Кейс / Рейтинг
├── data/cases.js          # банк клинических кейсов с разборами
├── stores/game.js         # Pinia: прогресс, баллы, уровни, рейтинг
├── views/
│   ├── DashboardView.vue   # статистика, уровень, рекомендации
│   ├── CasesView.vue       # банк кейсов с фильтрами
│   ├── CasePlayView.vue    # решение кейса: картина → вопросы → разбор
│   └── LeaderboardView.vue # таблица лидеров
└── components/
    └── ToastStack.vue      # всплывающие уведомления
```
